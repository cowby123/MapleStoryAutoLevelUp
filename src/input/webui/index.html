哪些設定跟著角色、哪些大家共用
        
跟著角色（每個設定檔各一份）：按鍵、攻擊方式與射程、群體技能、增益技能、喝水門檻、地圖與路線的選擇、找角色的方式與名牌、練功 / 休息循環、類人保護、符文 / 詛咒選項。

        大家共用：畫面串流與更新間隔、每秒處理張數（FPS）、真的輸入 / 模擬、找怪的辨識設定、偵測不到時停手的秒數、自動偵測角色開關；地圖本身的資料（路線圖、安全點、安全路線）也是共用的。

        「儲存」會把共用的寫到 ，其他寫到目前的設定檔。「清除我的設定」只清目前的設定檔。

切到「真的輸入」？

  
練功程式會真的對遊戲按鍵：移動、跳、攻擊、喝水。請先確認：

  
  • 遊戲在前景，輸入法是英數
  • 按鍵設定正確
  • 畫面上小地圖、玩家（隊伍紅條）都有偵測到
